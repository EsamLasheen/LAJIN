# LAJIN

Personal CTF walkthrough blog by Esam Lasheen.

## About

This repository contains my static blog for CTF walkthroughs, security research, and personal notes.

## Getting Started

1. Install dependencies:
   ```sh
   pnpm install
   ```
2. Run the site locally:
   ```sh
   pnpm dev
   ```
3. Build for production:
   ```sh
   pnpm build
   ```
4. Preview the production build:
   ```sh
   pnpm preview
   ```

## Content

- Write posts in `src/content/posts/`
- Use `pnpm new-post <name>` to create a new post

## Deployment

This project is configured for GitHub Pages:

- Astro site is set to `https://esamlasheen.github.io/LAJIN`
- Base path is `/LAJIN`
